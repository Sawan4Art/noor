# نور المسلم — تطبيق إسلامي أصلي بلغة كوتلن

مؤذن، مصحف، أذكار، مسبحة وويدجت — مبني بالكامل **Kotlin + Jetpack Compose** بلا أي طبقة ويب.

> هذا التطبيق صدقة جارية على روح المرحوم بأذن الله — والد المالك.

## الحالة (إعادة البناء الكوتلنية — أكتوبر 2026)

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1 — الأساس | مواقيت دقيقة (محرك مطابق للمرجع باختبار ذهبي) + الموقع واسم المدينة + التاريخ الهجري + ثيمات فخمة | ✅ |
| 2 — المصحف | 604 صفحات بالتجويد الملون + التلاوة والكاش | ⏳ قادمة |
| 3 — الأذكار | الأذكار + المسبحة + القبلة + الويدجت | ⏳ قادمة |
| 4 — الخدمات | الأذان في الخلفية + الإقامة + السحور والقيام + التحديث الداخلي | ⏳ قادمة |

نسخ ألفا التجريبية تُبنى بمعرّف منفصل (`.alpha`) لتُثبَّت جنب النسخة المستقرة.
النسخة المستقرة الأخيرة من الطراز السابق: `v0.4.2` (فرع `legacy-web`).

## البناء

```bash
./gradlew :app:assembleAlpha        # نسخة ألفا للتجربة
./gradlew :app:testReleaseUnitTest  # الاختبارات — ذهبية المواقيت
```

النسخة `release` تُوقَّع في CI من أسرار المستودع (`KEYSTORE_BASE64`...).
مفتاح التوقيع الاحتياطي في المستودع الخاص `Sawan4Art/noor-secrets`.

## البنية

```
app/src/main/kotlin/com/sawan4art/noor/
├── domain/          # المحرك: المواقيت الفلكية، الموقع، الجيوكودينج
├── data/            # الإعدادات (DataStore)
├── ui/              # Compose: الثيم، الرئيسية، الإعدادات
└── util/            # الهجري، تنسيق الأوقات
```
